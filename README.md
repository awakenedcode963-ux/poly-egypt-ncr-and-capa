# بوابة بولو إيجيبت للجودة

بوابة متكاملة لإدارة طلبات الإجراءات التصحيحية والوقائية (CAPA) وتسجيل بلاغات الأعطال.

## كيفية رفع اللوجو:
يرجى سحب وإفلات صورة اللوجو من جهازك إلى مجلد `public/assets/` داخل المشروع، وتسمية الملف `polo-egypt-logo.png`.
ستقوم الواجهة البرمجية بقص الهوامش البيضاء تلقائياً ليظهر اللوجو بأفضل شكل.
